# KodNest Premium Build System

A calm, intentional, and coherent design system for serious B2C SaaS products.

## Design Philosophy

- **Calm**: Minimal noise, no gradients, no glassmorphism.
- **Intentional**: Every pixel usage is deliberate.
- **Coherent**: Consistent spacing, typography, and color usage.
- **Confident**: Large serif headings, clear actions, solid primary buttons.

## Color System

- **Background**: #F7F6F3 (Off-white)
- **Primary Text**: #111111 (Deep Black)
- **Accent**: #8B0000 (Deep Red)
- **Success**: #4CAF50 (Muted Green)
- **Warning**: #FFB300 (Muted Amber)

## Typography

- **Headings**: Playfair Display (Serif)
- **Body**: Inter (Sans-serif)
- **Scale**: 16-18px base size, 1.6 line height.

## Spacing

Scale: 8px, 16px, 24px, 40px, 64px.

## Components

- **Layout**: Top Bar -> Context Header -> Split Workspace -> Proof Footer.
- **Buttons**: Primary (Solid Red), Secondary (Outlined), consistent hover states.
- **Inputs**: Clean borders, focus states using primary text color.
- **Cards**: Subtle borders, no shadows.

## Usage

Run the development server:
`npm run dev`

Open [http://localhost:5173](http://localhost:5173) to view the system.
